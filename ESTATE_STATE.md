Two columns. An agent may write in **Observation** only: what it measured, the command it ran, the
output, and the time. An agent may **never** write in **Founder approval**, and may never use the
words live, done, core or operational about a component. Observe and propose. The founder approves.

Proof earns a row, not a tick. A green test result gets a component onto this board with its
evidence attached; it does not move the component anywhere.

session start. The mechanical half — a pull-request check that fails any diff writing the approval
column — is **not built yet**. That is the residual.
