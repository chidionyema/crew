# Demo: the research grade is regenerated every hour

Founder ruling 2026-08-27 (crew#508): "we cant afford to rest on laurels and fall behind on research". A page a session regenerates by hand goes stale the day sessions stop; this one is regenerated by the same hourly job that publishes the science page.

```
python3 science/research_grade.py --print      # what the next snapshot will publish
grep -n 'regenerate the research grade' scripts/estate-snapshot
git log -1 --format='%h %ad' -- docs/science/RESEARCH-GRADE.md   # the last hourly publish
```

Expected: the page shows an `## Outward` and an `## Inward` block, each graded, generated within the last hour.
