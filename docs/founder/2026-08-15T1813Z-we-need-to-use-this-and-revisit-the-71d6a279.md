Two specific options:
Option A: Commit to Teal (Monochromatic)
Make the logo teal your hero. Use a darker shade (#0d7377) for buttons and a lighter tint for backgrounds/hover states. This is clean, modern, and ownable. It says: "We have a point of view."
Option B: Teal + Charcoal (Editorial)
Keep teal for the logo, charts, and key highlights. Use charcoal (#2d3436) for buttons and primary text. This feels like a premium research publication — serious but not corporate. The teal becomes the "smart" accent; the charcoal provides weight without the coldness of navy.
Fix the tags
Those category colors need to be pulled from a single family. If you go with Option B, make all tags charcoal text on tinted backgrounds — e.g., light teal tint for one category, light amber tint for another, light grey for a third. Same saturation, same lightness. Suddenly the page feels designed, not assembled.
The bottom line
The navy blue looks like a placeholder. Mumchimp's brand is about rigorous filtering that survives scrutiny — the color palette should feel curated too. Either go all-in on teal, or pair it with charcoal. Ditch the navy, systematize the tags, and the whole site will feel intentional.
