# Founder documents — the verbatim record

Every document the founder pastes into any session is captured here verbatim on
arrival, one file per document, timestamped. Never paraphrase one from memory and
never search transcripts: the file is the record.

This store moved from the private `claude-estate` repo (`~/.claude/docs/founder/`)
on 2026-08-31 on the founder's order: estate context is vendor-neutral and lives
where every crew agent reads it, not in a Claude-branded folder. Until the capture
hook in `claude-guards` is repointed here, a newly pasted document lands in the old
path first and is mirrored across by the migration issue's sweep.

Read one back: `ls docs/founder | grep <word>` or the capture tool's `--list --grep`.
