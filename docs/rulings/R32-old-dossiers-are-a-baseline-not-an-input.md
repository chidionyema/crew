# R32: old dossiers are a baseline to beat, not an input

Founder, 2026-08-25, verbatim: "why are we concerned with the old dossiers when we want to exponentially improve things, old dossiers were duck taped together, our new capabilities should be sneering at this and want to prove they can generate much better ideas for all scales."

Meaning: the research engine generates from scratch at every scale (one company, one market, the estate). It is never fed, tuned to or scored against the old prospector corpus. The corpus has one use: a side-by-side baseline the engine must beat. A plan whose first step is "load the old dossiers" is the old system with a new name. Sharpens R31.
